# Portafolio Electrónico - Universidad de Cartagena

## Cómo abrirlo
Abre `index.html` en el navegador.

## Estructura
- `index.html`: portada / Inicio
- `menu.html`: menú principal
- páginas de cada actividad: listas para completar
- `css/style.css`: diseño
- `js/script.js`: interacciones
- `imagenes/`: logo y fotografía

## Para subirlo a GitHub Pages
1. Crea un repositorio en GitHub.
2. Sube todos estos archivos y carpetas.
3. En GitHub entra a Settings > Pages.
4. En Source selecciona Deploy from a branch.
5. Selecciona la rama `main` y la carpeta `/root`.
6. Guarda y espera a que GitHub publique el sitio.

No cambies los nombres de las carpetas `css`, `js` e `imagenes`.
